# Thuật ngữ tiếng Việt

Dùng các cách viết sau trên toàn bộ bản tiếng Việt:

| English             | Tiếng Việt                       |
| ------------------- | -------------------------------- |
| pull request        | pull request (PR)                |
| check run           | check run                        |
| workflow            | workflow                         |
| step                | bước                             |
| recipe              | recipe                           |
| toolkit             | toolkit                          |
| trigger             | điều kiện kích hoạt (trigger)    |
| base branch         | nhánh đích (base branch)         |
| head branch         | nhánh nguồn (head branch)        |
| merge               | merge                            |
| retry               | chạy lại (retry)                 |
| recreate            | tạo lại (recreate)               |
| tracker comment     | comment theo dõi (tracker)       |
| output pull request | PR kết quả                       |
| group               | nhóm                             |
| quota               | hạn mức (quota)                  |
| maintainers         | BWV Workflows maintainers        |
| Project Leader      | Project Leader (PL)              |
| Dev & Com           | Dev & Com                        |
| write access        | quyền ghi (write access)         |
| branch protection   | bảo vệ nhánh (branch protection) |
| status comment      | comment trạng thái               |
| queued              | đang xếp hàng                    |
| published           | đã xuất bản                      |
| publication         | xuất bản                         |
| step output         | nội dung trả về của bước         |
| sync pull request   | pull request đồng bộ             |
| needs mapping       | cần chọn nguồn                   |
| preview             | bản xem trước                    |

Dòng vai trò dùng `👤 Phụ trách: Project Leader`, `👤 Phụ trách: Dev & Com`, hoặc `👤 Phụ trách: Project Leader và Dev & Com`.

Giữ nguyên tiếng Anh như trên GitHub và trong comment của bot: nhãn giao diện, tên check run, lệnh `/bwv`, khóa YAML, code và đường dẫn file. In đậm nhãn giao diện. Khi nhãn xuất hiện lần đầu, thêm lời giải thích ngắn bằng tiếng Việt trong ngoặc.
