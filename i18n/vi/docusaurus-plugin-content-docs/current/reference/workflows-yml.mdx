👤 Phụ trách: Project Leader

Đặt cấu hình repository tại `.bwv/workflows.yml`. BWV Workflows đọc file này từ nhánh đích (base branch) của pull request. Vì vậy, pull request không thể thay đổi workflow đang kiểm tra chính nó.

Bắt đầu với [Workflow đầu tiên của bạn](../getting-started/first-workflow). Sau đó, dùng tài liệu tham khảo được tạo tự động này để kiểm tra các trường lồng nhau, giá trị bắt buộc, giá trị mặc định và giá trị được phép. Giữ `version: 1` ở cấp cao nhất của file.

Phần tham khảo bên dưới được tạo từ chính schema mà BWV Workflows sử dụng. Đừng sao chép mọi trường. Chỉ thêm điều kiện kích hoạt (trigger), các bước, giá trị mặc định và hành động khi thành công mà workflow của bạn cần.
