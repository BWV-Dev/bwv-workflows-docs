## Khi nào bạn cần trang này

Hãy chạy lại (retry) sau khi bạn đã sửa nguyên nhân làm workflow hoặc nhóm bản dịch bị lỗi. Bạn cần quyền ghi (write access) vào repository để yêu cầu chạy lại.

Có ba cách: chọn ô được hiển thị, chọn **Re-run** trên một check run (ô kết quả kiểm tra hiện ở tab **Checks** của PR), hoặc comment bằng `/bwv retry`.

## Từng bước thực hiện

### Cách 1: Chọn ô **Retry**

1. **Dev hoặc Com:** Mở comment trạng thái hoặc comment theo dõi (tracker) bản dịch của BWV Workflows.
2. Nếu đang xem tracker, hãy mở rộng **Actions**.
3. Chọn ô **Retry** cho workflow hoặc nhóm bị lỗi.
4. Chờ bot bỏ chọn ô và hiển thị một dòng **queued** hoặc **running**.

### Cách 2: Chọn **Re-run** trên một check run

1. **Dev hoặc Com:** Mở check bị lỗi có tên `bwv/<workflow>` hoặc `bwv/<workflow>/<group>`.
2. Mở menu của check run.
3. Chọn **Re-run** cho check run đó.

Với workflow có nhóm, check của workflow sẽ chạy lại những nhóm mà tracker vẫn cho phép. Check của một nhóm chỉ chạy lại chính nhóm đó.

### Cách 3: Thêm comment vào pull request

Comment một trong các lệnh sau trên pull request:

```text
/bwv retry
```

Lệnh này yêu cầu chạy lại mọi tác vụ hiện đủ điều kiện.

```text
/bwv retry translate-docs
```

Lệnh này yêu cầu chạy lại một workflow. Hãy thay `translate-docs` bằng đúng tên workflow hoặc nhóm được hiển thị trong check hay tracker.

Sau khi chấp nhận lệnh, bot thêm phản ứng 👍 rồi trả lời kết quả bằng một comment.

{/* TODO(screenshot): A `/bwv retry source-pr-7` pull request comment with the accepted 👍 reaction from BWV Workflows, with repository name, avatars, and pull request number blurred */}

Xem [bảng lệnh /bwv](/reference/commands) để biết danh sách đầy đủ được tạo tự động.

### Đọc câu trả lời của bot

| Câu trả lời                                 | Ý nghĩa                                                            |
| ------------------------------------------- | ------------------------------------------------------------------ |
| **queued**                                  | Yêu cầu đã được chấp nhận và đang xếp hàng.                        |
| **after the run in progress finishes**      | Yêu cầu đang chờ lần chạy hiện tại kết thúc rồi mới chạy.          |
| **after the work already waiting**          | Một yêu cầu khác đã xếp hàng trước yêu cầu này.                    |
| **already covered by a run that is queued** | Tác vụ đang xếp hàng đã bao gồm yêu cầu của bạn. Đừng yêu cầu lại. |
| **running since …**                         | Lần chạy lại bạn yêu cầu đã bắt đầu.                               |
| **Nothing to retry yet: … is running now**  | Chính workflow hoặc nhóm đó đang chạy. Hãy chờ kết quả.            |

Nếu bạn gõ sai hoặc dùng lệnh `/bwv` không tồn tại, bot không chạy gì và trả lời bằng các lệnh được hỗ trợ:

## Điều gì xảy ra tiếp theo

Khi bắt đầu chạy lại, bot dùng phiên bản mới nhất của pull request đang mở. Với pull request đã merge, bot chạy lại tác vụ từ lần merge đó. Comment trạng thái, tracker và check run sẽ cập nhật khi yêu cầu đang chờ, bắt đầu và kết thúc.

:::caution Đừng chạy lại một nhóm đã published
Nhóm có PR kết quả nghĩa là đã được xuất bản. Bot sẽ từ chối `/bwv retry <group>` cho nhóm đó. Hãy kiểm tra pull request hiện có, hoặc dùng **Recreate** nếu PR đã bị đóng mà chưa merge.
:::

:::note Tôi có thể dùng **Re-run all checks** không?
Hãy dùng thao tác **Re-run** cho đúng check `bwv/…`, một ô **Retry** hoặc `/bwv retry`. Thao tác **Re-run all checks** cho toàn bộ bộ kiểm tra không phải cách đáng tin cậy để yêu cầu đúng tác vụ BWV bạn muốn.
:::

:::note Tại sao yêu cầu của tôi không bắt đầu ngay?
Mỗi lần chỉ có một lần chạy của cùng một tác vụ được thực hiện. Bot giữ yêu cầu đủ điều kiện phía sau tác vụ đang chạy và hiển thị thời gian chờ đó trong tracker hoặc một check run đang xếp hàng.
:::
