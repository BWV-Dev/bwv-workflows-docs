## Khi nào bạn cần trang này

Hãy dùng **Recreate** khi một PR kết quả đã bị đóng mà chưa merge và bạn muốn bot mở một pull request mới. Việc đóng PR kết quả được coi là một quyết định có chủ ý. Vì vậy, lần chạy thông thường hoặc chạy lại (retry) sẽ không mở lại PR đó.

Bạn cần quyền ghi (write access) để yêu cầu tạo lại (recreate).

## Từng bước thực hiện

### Cách 1: Chọn ô **Recreate**

1. **Dev hoặc Com:** Quay lại pull request nguồn hoặc pull request đồng bộ có comment theo dõi (tracker).
2. Mở rộng **Actions**.
3. Chọn **Recreate pull request `<group>`**.
4. Chờ bot bỏ chọn ô và báo yêu cầu tạo lại đang xếp hàng hoặc đang chạy.

Với workflow không có nhóm, hãy dùng ô **Recreate pull request** trong comment trạng thái của workflow đó.

### Cách 2: Chọn **Recreate PR**

1. **Dev hoặc Com:** Mở PR kết quả đã đóng.
2. Mở check run (ô kết quả kiểm tra hiện ở tab **Checks** của PR) `bwv/<workflow>/<group>`.
3. Chọn **Recreate PR**.

Nút này có trên PR kết quả của workflow có nhóm. Với workflow không có nhóm, hãy dùng ô chọn trong comment hoặc lệnh bên dưới.

### Cách 3: Thêm lệnh

Trên pull request nguồn hoặc pull request đồng bộ, hãy comment:

```text
/bwv recreate source-pr-7
```

Thay `source-pr-7` bằng tên nhóm hoặc workflow được hiển thị trong tracker hay comment trạng thái. Lệnh này kiểm tra trạng thái hiện tại của pull request, nên vẫn dùng được ngay cả khi hàng của PR vừa đóng chưa kịp cập nhật.

## Điều gì xảy ra tiếp theo

Bot chạy lại tác vụ đó và mở một pull request mới từ cùng nhánh kết quả. Pull request cũ vẫn đóng. Khi xuất bản thành công, tracker đổi sang pull request mới.

Nếu yêu cầu phải chờ một lần chạy đang diễn ra, bot hiển thị yêu cầu ở trạng thái **queued** và bắt đầu sau khi lần chạy đó kết thúc.

:::caution Có người đã push lên nhánh kết quả
Bot không ghi đè các commit mà bot không nhận ra là của mình. Nếu check báo không thể thay thế nhánh kết quả, hãy giữ lại mọi thay đổi cần thiết. Sau đó, nhờ Project Leader của repository xóa nhánh hoặc đổi tên nhánh kết quả trong cấu hình. Cuối cùng, chạy **Recreate** lần nữa.
:::

:::note Kết quả đã có trên nhánh đích
Nếu tất cả kết quả cần có đã được thêm hoặc cập nhật trên nhánh đích (base branch) sau khi merge nguồn, thì không còn gì để tạo lại. Tracker hiển thị ✅ **already on** the base branch và không mở pull request mới.
:::

:::note Chỉ một phần kết quả có trên nhánh đích
Hãy xử lý các tệp được nêu trong **outputs partly on** the base branch. Sau đó, yêu cầu **Recreate** lần nữa. Pull request đã đóng vẫn nằm trong tracker cho đến khi nhóm được xử lý xong hoặc có bản thay thế được xuất bản.
:::

:::note Nút báo đã hết hạn
PR kết quả có thể đã được mở lại, merge hoặc tạo lại. Hãy quay về tracker và làm theo hàng hiện tại thay vì bấm lại.
:::
