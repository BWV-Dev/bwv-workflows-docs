# Tự động hóa công việc trong repository với BWV Workflows

👤 Phụ trách: Project Leader và Dev & Com

BWV Workflows là một GitHub App. App đọc cấu hình trong repository để chạy các công việc bằng Claude, báo cáo từng lần chạy trên GitHub và có thể xuất bản các thay đổi kết quả qua một pull request (PR).

<LandingCards />

:::tip Chọn hướng dẫn phù hợp
Project Leader bắt đầu với phần đưa repository vào sử dụng. Dev & Com bắt đầu với hướng dẫn làm việc trên pull request.
:::
