👤 Responsible: Project Leader

Put the repository configuration at `.bwv/workflows.yml`. BWV Workflows reads
it from a trusted ref: the pull request's base branch for a pull request run,
the pushed commit for a push run, or the selected target branch tip for a
manual run. A pull request therefore cannot change the workflow that evaluates
itself.

Start with [Your first workflow](../getting-started/first-workflow), then use this generated reference to check nested fields, required values, defaults, and allowed values. Keep `version: 1` at the root of the file.

The reference below is generated from the same schema used by BWV Workflows. Do not copy every field; add only the trigger, steps, defaults, and success action your workflow needs.
