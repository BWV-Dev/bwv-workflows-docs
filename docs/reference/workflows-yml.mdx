Put the repository configuration at `.bwv/workflows.yml`. BWV Workflows reads this file from the pull request's base branch, so a pull request cannot change the workflow that evaluates itself.

Start with [Your first workflow](../getting-started/first-workflow), then use this generated reference to check nested fields, required values, defaults, and allowed values. Keep `version: 1` at the root of the file.
