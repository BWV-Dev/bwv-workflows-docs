👤 Responsible: Dev & Com

Type a command as a new line in an issue or pull request conversation. Start the line with `/bwv`; text that only mentions or quotes a command does not run it. Manual `/bwv run` and batch `/bwv recreate #N` commands may use an issue; pull request retry, status, provenance, and grouped recreation commands belong on the affected pull request.

BWV Workflows carries out commands only for a user with write access to the repository. An unsupported command may return the command list, but it does not run workflow work. Do not edit an older comment into a command; add a new comment.
