👤 Responsible: Project Leader

Use recipe version 1 to package a reusable set of workflows or steps. A local recipe lives below `.bwv/recipes/` and starts with `apiVersion: 1`. A remote recipe uses the same format in its recipe repository.

BWV Workflows reads a local recipe from the same trusted base-branch commit as `.bwv/workflows.yml`. For a remote recipe, the full SHA in `uses:` selects the trusted commit.

Read [Recipes and toolkits](../configuring/recipes-and-toolkits) before authoring a recipe. Then use this generated reference for input types, recipe expressions, workflow recipes, and step recipes. A recipe must have exactly one body: `workflows` or `steps`.
