👤 Responsible: Project Leader

Ask the BWV Workflows maintainers to onboard the repository. Installation and
engine configuration are maintainer tasks.

## Workflow Summary

1. [Choose the repository](#1-choose-the-repository).
2. [Send the onboarding request](#2-send-the-onboarding-request).
3. [Wait for maintainer setup](#3-wait-for-maintainer-setup).
4. [Verify the GitHub App](#4-verify-the-github-app).

## Step-by-Step Instructions

### 1. Choose the repository

👤 Responsible: Project Leader

Collect the target repository name as `<owner>/<repo>`, for example
`acme/web-app`.

:::tip Choose where repository-specific recipes live
Shared recipes come from `BWV-Dev/bwv-workflows-recipes`. When a recipe is
specific to this repository, store it under `.bwv/recipes/` instead.
:::

### 2. Send the onboarding request

👤 Responsible: Project Leader

Send the BWV Workflows maintainers a request in this format:

```text
Repository: acme/web-app
```

The request only needs the repository name. Do not send tokens, App
credentials, or installation links.

### 3. Wait for maintainer setup

👤 Responsible: BWV Workflows maintainers

The maintainers:

1. Confirm that the target repository can use BWV Workflows.
2. Install or extend the **BWV Workflows** GitHub App installation for the
   target repository.
3. Make the official shared recipe repository available to that installation.
4. Confirm when the repository is ready for a workflow file.

Wait for that confirmation before adding `.bwv/workflows.yml`.

### 4. Verify the GitHub App

👤 Responsible: Project Leader

1. Open `acme/web-app` on GitHub.
2. Select **Settings**.
3. Select **GitHub Apps** under **Integrations**.
4. Confirm that **BWV Workflows** appears in the installed Apps for the
   repository.

![BWV Workflows listed under the repository's installed GitHub Apps](/img/screenshots/onboard-repository-github-app.png)

_Confirm that **BWV Workflows** appears under **Installed GitHub Apps**._

:::note Missing access
If **BWV Workflows** is not listed, ask the BWV Workflows maintainers to check
the installation. Do not try to install the App from a separate link.
:::

Continue with [Your first workflow](./first-workflow).
