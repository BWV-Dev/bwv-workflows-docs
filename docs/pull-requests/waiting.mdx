## When you see this

A yellow or in-progress BWV check is not always stuck. Read its title, summary, and tracker line before taking action. Most waits continue automatically.

## Step-by-step

### 1. Match the message

| What you see                                                     | What it means                                                                                 | What to do                             |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------- |
| **Waiting for quota**                                            | The current attempt used up the Claude quota.                                                 | Wait for the time shown.               |
| **Retrying automatically around HH:MM UTC**                      | The bot will try shortly after the reset time reported by Claude.                             | Wait. Do not tick **Retry**.           |
| ⏸️ **Stopped: Claude quota used up · retrying around HH:MM UTC** | A manual-run pass stopped. Work already published by earlier passes is kept.                  | Wait. The bot continues by itself.     |
| **Retrying automatically once the remaining workflows … finish** | Other workflows from the same request are still finishing before the retry time can be shown. | Wait. The bot will update the message. |
| **Waiting for a retry**                                          | A temporary problem stopped the attempt and another attempt remains.                          | Wait for the time shown.               |
| **running since …**                                              | Your Retry or Recreate request has started.                                                   | Wait for the result.                   |

“Around” is intentional; the next attempt may not start at the exact minute shown.

### 2. Open the check

1. **Dev or Com:** Open the pull request's **Checks** tab.
2. Find the latest `bwv/<workflow>` or `bwv/<workflow>/<group>` check.
3. Read the summary for the next retry time or the current step.
4. Return after the displayed time or after the current work finishes.

### 3. Wait through automatic infrastructure retries

A temporary infrastructure stop leaves the check in progress while automatic attempts remain. The bot shows **Waiting for a retry** and the next retry time. If no automatic attempt remains, the check fails and says **Infrastructure error**.

## What happens next

The bot reuses the waiting check run for the next attempt. It updates the status comment or translation tracker when the work resumes. The check finishes green after success or red after the final failed attempt.

:::caution Do not spam Retry
Another Retry does not make quota or infrastructure time pass sooner. Send one request, then follow the same check.
:::

:::caution Do not close and reopen the pull request
Closing or reopening is not a recovery action. It can change which work is eligible and does not bypass a wait.
:::

:::note When should I ask the maintainers?
Ask the BWV Workflows maintainers when the displayed retry time has passed and the check has not updated after a reasonable delay, or when the final result says **Infrastructure error**. Include a link to the pull request and the affected `bwv/…` check.
:::
